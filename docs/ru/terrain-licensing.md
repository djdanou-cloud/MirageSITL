# Решение о политике поставщиков рельефа

<!-- source-sha256: bb4be908bd771396699745ebf9728cd606575bcd7224554f735e5bfab6eea326 -->

Английский источник: [Source of truth](../decisions/terrain-licensing.md).

TASK-060 вводит границу конфигурации до кода загрузки/кеширования.
`providerPolicy(unknown)` проверяет ровно восемь полей и сохраняет неизменяемую
копию политики. Неизвестные поставщики, пустая атрибуция/лицензия, неверный TTL
и некорректные хеши разрешений отклоняются. Для тестов не нужен платный API-ключ.

Google live tiles разрешены только в оперативной памяти с TTL 0, offline false
и prefetch false. TTL 0 означает отсутствие предоставленного этим адаптером
права на хранение на уровне приложения; загрузчик по-прежнему обязан соблюдать
HTTP-директивы и текущие условия поставщика. Постоянный кеш R2, региональная
предзагрузка и распространение офлайн запрещены. Оплата API сама по себе
не даёт прав на офлайн/кеш. Будущее исключение для Google требует отдельного
проверенного изменения контракта; хеш от клиента ограничения не отключает.

Собственные/лицензированные данные могут запрашивать постоянное хранение,
офлайн или предзагрузку лишь с 64-символьным SHA-256 проверенного разрешения,
непустой лицензией и атрибуцией. Хеш идентифицирует документ, не проверяет его
правовой смысл. Проверенную конфигурацию предоставляет владелец развёртывания.
Тесты используют синтетические свидетельства и не дают прав на внешний набор
данных. TTL — целое от 0 до 31536000 секунд. Последующие модули (`packages/terrain/src/tiles-provider.ts` в TASK-061, `services/tiles-worker/` в TASK-063 и `services/tiles-worker/src/r2-cache.ts` в TASK-064) применяют эту неизменяемую политику в локальном и эмуляторном контуре; живые ключи Google API, развёртывание Cloudflare Worker и подключение рабочего бакета R2 остаются внешними (`BLOCKED_EXTERNAL`).
