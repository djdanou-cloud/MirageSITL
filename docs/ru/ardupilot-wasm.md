# Решение об осуществимости ArduPilot в браузере
<!-- source-sha256: 250f81e78689ccadcefe30a0086dc4c4c27a6725aa7325db9d1edc26310a5349 -->

Решение: BLOCKED_EXTERNAL для исполнения прошивки; исследовательская проверка TASK-044 реализована. TASK-045–047 остаются открыты. WebAssembly в Node не является браузерным портом ArduPilot. Коммит прошивки 8ab6afde107a91df1b5f60ade8f333cb8a61b190 совпадает с JSON-оракулом TASK-041. Пути, HTTPS-ссылки, фактические хеши и длины байтов закреплены в native/ardupilot/source.lock.json. Четыре официальных файла загружены и изучены 2026-10-17.

| Возможность | Наблюдаемое свидетельство | Требуемая работа |
| --- | --- | --- |
| Планировщик | AP_HAL_SITL/Scheduler.cpp использует pthread_self и нативные потоки/семафоры | Реализовать кооперативные lockstep-часы, ограниченную семантику потоков/прерываний и завершение |
| UART/сеть | AP_HAL_SITL/UARTDriver.cpp использует нативные сетевые/UART-точки | Заменить нативные сокеты ограниченными Worker-mailbox и I/O-мостом |
| Хранилище | AP_HAL_SITL/Storage.cpp использует open/pread/pwrite и flash-файлы | Предоставить виртуальное постоянное хранилище, атомарную инициализацию и восстановление |
| Компилятор | probe-ardupilot-wasm.mjs вызывает emcc --version; отсутствие фиксируется | Закрепить/установить SDK с исходными хешами, собрать настоящую прошивку |
| Браузерная память | Проба фиксирует только наличие WebAssembly/SAB | Проверить фиксированную память, экспорты, планировщик и аллокатор под нагрузкой |
| Лицензии | COPYING.txt закреплён; исходник GPL изучен | Проверить обязательства всей прошивки/зависимостей и распространение соответствующего исходного кода |
| Паритет | Нет драйвера/трассы нативного полёта и WASM-артефакта | Native/WASM arm/takeoff/land/failsafe и паритет траектории 30 с |

Запуск: node scripts/probe-ardupilot-wasm.mjs. Он пишет test-results/validation/ardupilot-wasm-feasibility.json и завершается с 2, пока порт отсутствует. Необязательный MIRAGE_ARDUPILOT_SOURCE проверяется по хешам отдельных файлов; MIRAGE_EMCC задаёт явный компилятор. Найденный компилятор и совпадение исходников не превращают нереализованные возможности в true. Загрузчик, HAL-заглушка и пустой модуль прошивки не предоставляются.
