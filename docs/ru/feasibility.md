# Свидетельства осуществимости ArduPilot
<!-- source-sha256: 5a5e06b6351558ac7c04053b61633ca1b5c69707175f2714643a0da678500109 -->

Фиксация источников записывает наблюдаемые SHA-256 официального коммита, а не хеш исполняемой прошивки. В этой итерации нативный бинарник и WASM-прошивка не собирались. JSON-протокол закреплён без изменения. Воспроизводимая проба запускается из корня; точные upstream-файлы получают по URL фиксации через TLS и сверяют хеши до анализа. Подробные наблюдения и требуемая реализация находятся в docs/decisions/ardupilot-wasm.md.

Проверка не допускает режим исполнения. Будущее положительное решение требует настоящего порта HAL/планировщика/хранилища/сети, проверки лицензий, идентичности компилятора/артефакта и успешного нативного паритета, затем TASK-045–047. Наличие runtime Node и программные unit-тесты недостаточны.


Продолжение TASK-045 (2026-10-19) заменяет исходные наблюдения TASK-044 об отсутствии сборки выше: неизменная штатная плата wasm имеет воспроизводимый локальный артефакт, проверенный настоящий запуск Chromium Worker/pthread, serial-ответы параметров, восстановление постоянного EEPROM и остановку. TASK-042/059 дают отдельные настоящие нативные эталоны полёта/отказов. TASK-046 по-прежнему отвечает за браузерный HAL/физику/время MirageSITL, TASK-047 — за паритет полёта; распространение артефакта сохраняет шлюз решения. Локальное bootstrap-свидетельство не включает браузерный режим полёта.
