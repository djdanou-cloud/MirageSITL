Английский источник: [Source of truth](../../AGENTS.md). Изменения обновляют оба языка в одной задаче.

Этот файл является указателем, а не набором правил. Авторитетный рабочий
процесс агентов для этого репозитория находится в корневом
[CLAUDE.md](../../CLAUDE.md). Открывать и читать его перед каждой итерацией,
затем следовать его правилам о языке, синхронизации документации,
выполнении задач, проверке и evidence.

Не копировать правила из CLAUDE.md в этот файл или другую конфигурацию
агентов. При изменении правила менять только CLAUDE.md и его русское
зеркало. Загружает ли конкретный клиент этот файл автоматически, зависит от
клиента; при сомнении открыть CLAUDE.md явно.

CLAUDE.md, в свою очередь, направляет агентов к утверждённому
[PROJECT_SCOPE.md](PROJECT_SCOPE.md) и [плану фазы 1](PHASE1_PLAN.md) до выбора
задачи.
