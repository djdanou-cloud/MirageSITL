# Установка MirageSITL на macOS (TASK-152)

<!-- source-sha256: f22f19b7727e31e78e908872a3d5daa0abfd2243fc5c8fc355184ac898e7cab1 -->

Английский источник: [install-macos.md](../operations/install-macos.md).

Фаза 1 работает на macOS с процессором Apple Silicon и в Chrome. Установщик
готовит папку запускателя, которой пользуется локальный запускатель
([runbook](runbook.md), TASK-151); после установки запускатель, ArduPilot
SITL и веб-приложение работают без сети.

## Перед установкой

* macOS на Apple Silicon.
* Node.js 24 LTS (`.nvmrc` репозитория) и этот репозиторий с установленными
  пакетами npm (`npm ci`).
* Инструменты командной строки Xcode (`xcode-select --install`), с которыми
  приходят git, clang и Python 3.9 или новее.
* Подключение к сети только на время установки и около 3 ГБ свободного места.

## Установка

```bash
node scripts/install-macos.mjs
```

Параметры: `--home DIR` выбирает папку запускателя (по умолчанию
`~/Library/Application Support/MirageSITL/launcher`, как у самого
запускателя; `MIRAGE_LAUNCHER_HOME` задаёт обе), `--jobs N` — параллельность
сборки, а `--plan` печатает шаги, ничего не меняя. Установщик:

1. проверяет компьютер: macOS на Apple Silicon, Node.js 24, инструменты
   командной строки Xcode, git и Python 3.9 или новее, называя исправление
   для каждого отсутствующего;
2. создаёт `venv/` и устанавливает пакеты Python из
   `scripts/install/requirements-macos.txt` через `pip --require-hashes`:
   каждый пакет закреплён на одной версии, и устанавливаются только файлы с
   перечисленными SHA-256 (pymavlink 2.4.50 и пакеты, нужные сборке ArduPilot,
   как их использовала TASK-127);
3. загружает ArduPilot на коммите из `scripts/sitl.lock.json` в
   `sources/ardupilot` с десятью подмодулями, нужными сборке SITL; git
   проверяет каждый объект по его хешу, а рабочая копия должна быть чистой;
4. собирает нативный ArduCopter SITL через waf в `build/`, допускает его как
   нативный для компьютера исполняемый файл Mach-O64 и записывает в
   `catalog.json` с SHA-256 исполняемого файла и `copter.parm` ArduPilot;
5. загружает UAVLogViewer на коммите и с подмодулем парсера из
   `third_party/uavlogviewer/source.lock.json` в `sources/uavlogviewer` и
   проверяет хеш его LICENSE, затем собирает пропатченный офлайн-просмотрщик в
   `uavlogviewer/` скриптом `scripts/build-uavlogviewer.mjs` (TASK-179: патчи
   из `third_party/uavlogviewer/patches/`, закреплённые npm-пакеты, лицензионные
   уведомления и `build-manifest.json`); повторный запуск пересобирает его,
   только если манифест больше не совпадает с серией патчей или файлами на диске;
6. пишет `install-manifest.json`: каждый установленный элемент с версией,
   SHA-256, размером и лицензией из его строки `config/offline-inventory.json`.

Повторный запуск заново проверяет каждый шаг и пропускает уже выполненное,
поэтому прерванная установка продолжается. Код выхода 0 — установлено,
1 — шаг не удался, 2 — не хватает предварительного условия компьютера.

## Первый запуск

```bash
npm run start -w @mirage/launcher
npm run dev
```

Запускатель печатает путь к файлу токена, но не сам токен. Откройте
приложение в Chrome по адресу `http://127.0.0.1:5173`, перейдите на вкладку
Project и в разделе «Setup: local launcher and prerequisites» введите порт
запускателя (47800, если его не меняет `MIRAGE_LAUNCHER_PORT`) и вставьте
токен из файла. «Check setup» перечисляет каждое предварительное условие
(платформа, Node.js, хранилище, pymavlink, установка и совместимая сборка
SITL) как OK, Missing или Needs attention с указанием, что делать. Токен
остаётся на этой странице: он передаётся только в заголовке Authorization и
не сохраняется. Проверка также различает неотвечающий запускатель и
отклонённый токен. Проверка установки заново вычисляет SHA-256 каждого файла,
записанного в манифест внутри папки запускателя.

## Проверка (TASK-152)

`tests/install-macos.test.ts` проверяет проверки компьютера, закреплённые
требования, правила манифеста и `--plan`; если `.cache/task-152/home`
содержит чистую установку, тест заново вычисляет каждый записанный хеш и
требует, чтобы каждое предварительное условие было OK.
`tests/browser/first-run.spec.ts` запускает настоящий запускатель с
поддельной сборкой SITL и проверяет по нему вкладку Project: недоступный
порт, отклонённый токен, каждое предварительное условие с исправлением,
отсутствие токена в адресе, хранилище и тексте страницы, ширину 390 px без
горизонтальной прокрутки и отсутствие нарушений axe. Запись дорожной карты
фиксирует чистую установку на эталонном Mac.
