# Тактические иконки, аудио авионики и контекстные подсказки (`InfoTip`) — План реализации

<!-- source-sha256: 6380330df3d26d9becac6faef98ee3a2d419700d287a7ba5b7109b7d0c333413 -->

Английский язык является источником истины в репозитории. [Source of truth](../../ui_implementation_plan.md).

Этот план объединяет три согласованных уровня в `@mirage/web`:
1. **Дружелюбные к новичкам контекстные всплывающие подсказки (`InfoTip`)** рядом с каждой основной функцией, полётным прибором и инженерной настройкой.
2. **Тактические / военные иконки GCS** (`lucide-react` + пользовательские встроенные SVG 1px в стиле ИЛС/НАТО).
3. **Процедурное аудио авионики без внешних файлов** (синтезатор `Web Audio API` с кнопкой отключения звука Mute/Unmute в верхней панели).

## 1. Ограничения безопасности и совместимость с тестами (Критические требования)

В MirageSITL действуют строгие автоматизированные проверки в `tests/browser/` (`app-shell.spec.ts`, `accessibility.spec.ts`, `simulation.spec.ts`, `aircraft-editor.spec.ts`, `card-editor.spec.ts`, `sensors-tab.spec.ts`). Чтобы гарантировать **отсутствие регрессий в тестах**:
- **Сохранение точных доступных имён (`exact: true`):** Многие тесты ищут элементы управления через `getByRole("button", { name: "...", exact: true })`, `getByRole("tab", { name, exact: true })` и `getByLabel("...", { exact: true })`.
  - Все декоративные иконки внутри кнопок, вкладок и заголовков ОБЯЗАНЫ иметь `aria-hidden="true"` и не содержать текстовых узлов.
  - **Триггеры `InfoTip` НИКОГДА НЕ ДОЛЖНЫ вкладываться внутрь элементов `<label>` или `<button>`.** Вместо этого размещайте `<InfoTip>` рядом с заголовками, строками `legend` или внутри flex-контейнера *рядом* с `<label>`, чтобы доступная метка поля ввода оставалась на 100% неизменной.
- **Мобильный экран 390 px и отсутствие горизонтального переполнения:** `accessibility.spec.ts` и `app-shell.spec.ts` проверяют `document.documentElement.scrollWidth <= innerWidth` при разрешении `390×844` на всех 12 вкладках.
  - Всплывающие подсказки используют безопасное для области просмотра позиционирование (`position: fixed` или ограниченный по координатам поповер, привязанный к прямоугольнику триггера), чтобы никогда не увеличивать `documentElement.scrollWidth`.
- **Ноль нарушений Axe:** `InfoTip` использует семантическую кнопку `<button type="button" className="info-tip-trigger" aria-label="More information: ...">` с поддержкой `aria-expanded` / `role="tooltip"`, фокусом с клавиатуры (`Focus` / `Hover` / `Click`) и закрытием по клавише `Escape`.
- **Изоляция физического цикла без аллокаций:** Синтез звука и всплывающие подсказки интерфейса работают строго в главном потоке Main (`apps/web/src/ui/`). Файл [`physics.worker.ts`](../../apps/web/src/physics.worker.ts) остаётся без изменений.

## 2. Новые общие модули интерфейса (`apps/web/src/ui/`)

### A. Компонент контекстной подсказки: `apps/web/src/ui/InfoTip.tsx`
Компактный тактический значок `?` / `Info` (иконка `CircleHelp` / `Info` размером `14×14 px` из `lucide-react`), который открывает тёмное всплывающее окно в стиле MFD при **наведении мыши**, **фокусе с клавиатуры** или **нажатии/клике** (для мобильных и сенсорных экранов):
- **Визуальный стиль:** Фосфорно-циановая рамка (`#36574e`), глубокий тёмно-сланцевый фон (`#0c1821`), чёткий моноширинный заголовок + понятное объяснение на простом языке (`11px`, максимальная ширина `260px`), опциональная строка **«Why it matters»** или **«Safe value / tip»**.
- **Умное ограничение по краям экрана:** При наведении или фокусе измеряет `getBoundingClientRect()` и удерживает координаты `left`/`top` в пределах `[8px, window.innerWidth - 268px]`, чтобы окно никогда не обрезалось за краем экрана и не вызывало горизонтальную прокрутку при ширине `390px`.

### B. Процедурный синтезатор авионики: `apps/web/src/ui/audio.ts`
Контроллер `TacticalAudio` на базе Web Audio API без внешних зависимостей:
- **Переключатель звука в верхней панели** в [`AppShell.tsx`](../../apps/web/src/shell/AppShell.tsx): кнопка с иконкой `Volume2` / `VolumeX` (`aria-label="Toggle tactical audio"`, `aria-pressed`), сохраняющая состояние в `localStorage` (`mirage.audio.enabled`).
- **Синтезируемые звуковые сигналы (лицензия MIT / 100% свободный код):**
  1. `click()`: механический щелчок тумблера длительностью `15 ms` с фильтром верхних частот (`1800 Hz → 400 Hz`) при переключении вкладок, нажатии Start/Pause/Reset и смене режимов.
  2. `arm()` / `disarm()`: восходящий двухтональный сигнал готовности (`880 Hz → 1320 Hz`) при взведении двигателей (Arm); нисходящий сигнал безопасности (`960 Hz → 480 Hz`) при отключении двигателей (Disarm).
  3. `faultAck()`: двойной отрывистый импульс в стиле СПО/RWR (`2 × 60 ms` на частоте `1046 Hz`), когда рабочий поток подтверждает (ACK) команду отказа или РЭБ от инструктора.
  4. `caution()`: двухтональный предупреждающий сигнал MIL-STD (`800 Hz / 640 Hz`, `280 ms`), срабатывающий однократно при переходе в состояние `InputFailsafe`, `faulted` или `EKF STALE` / `DEGRADED`.
  5. `reject()`: низкий сигнал отклонения ввода авионики (`320 Hz + 340 Hz`, `150 ms`), когда команда отклонена или не прошла проверку.
  6. `recordPip()`: чистый маркерный сигнал телеметрии (`1200 Hz`, `70 ms`) при запуске и остановке записи AAR.

## 3. Где будут интегрированы подсказки (`InfoTip`) и тактические иконки

### A. Заголовок оболочки и навигация ([`AppShell.tsx`](../../apps/web/src/shell/AppShell.tsx), [`ProjectBar.tsx`](../../apps/web/src/shell/ProjectBar.tsx))
- **Тактические иконки:**
  - Аккуратные иконки `13px` с `aria-hidden="true"` внутри каждой из 12 вкладок навигации (`FolderKanban` для Project, `Plane` для Aircraft, `Cpu` для Components, `Radar` для Sensors, `ZapOff` для Faults, `CloudWind` для Weather, `Route` для Flight tasks, `Sliders` для Parameters, `Database` для Logging, `Play` для Run, `FlaskConical` для Experiments, `LineChart` для Analysis).
  - Кнопка включения/выключения звука (`Volume2` / `VolumeX`) в `.shell-header`.
- **Информационные подсказки (`InfoTip`):**
  - **Панель проекта (`ProjectBar`):** Объясняет, что проекты хранятся локально в IndexedDB вашего браузера (облачный аккаунт не требуется) и могут экспортироваться в виде архивов `.mirageproj`.

### B. Вкладка `Run` — Область полёта, ИЛС и консоль пилота ([`App.tsx`](../../apps/web/src/App.tsx), [`PilotHud.tsx`](../../apps/web/src/hud/PilotHud.tsx), [`SerialConnect.tsx`](../../apps/web/src/SerialConnect.tsx))
- **Тактические иконки и символика ИЛС (HUD):**
  - Обновление окна авиагоризонта в [`PilotHud.tsx`](../../apps/web/src/hud/PilotHud.tsx) с помощью встроенного SVG **шкалы тангажа в стиле MIL-STD и символа визирной линии самолёта (`—v—`)**, а также иконок состояния (`Satellite`, `ShieldAlert`).
  - Добавление микро-иконок телеметрии в `.hud-bottom` (`ArrowUpFromLine` для высоты AGL, `Gauge` для скорости, `BatteryCharging` для питания, `Compass` для режима управления).
  - Добавление иконок для кнопок `Arm motors` / `Disarm motors` (`Power` / `ShieldAlert`), вкладок `Demo input` / `USB / EdgeTX` (`Sliders` / `Gamepad2`) и `Connect serial` (`Plug` / `Unplug`).
- **Подсказки для начинающих (`InfoTip`):**
  1. **Бэкенд полёта (`Synthetic demo` против `ArduPilot SITL`):** Объясняет разницу между встроенной упрощённой моделью квадрокоптера и полноценной прошивкой ArduPilot SITL.
  2. **Индикатор координат (`DEMO QUAD / NED`):** Объясняет авиационную систему координат **NED (Север-Восток-Вниз)** и высоту **AGL (над уровнем земли)**.
  3. **ИЛС пилота (`EKF / Attitude`):** Объясняет работу авиагоризонта (крен/тангаж) и роль **EKF (расширенного фильтра Калмана)** в автопилоте дрона.
  4. **Метрики Physics / Main Thread / Scheduler:**
     - *Physics Hz:* Почему физика работает в отдельном потоке Worker с фиксированной частотой `400 Hz` (шаг `2.5 ms`) независимо от частоты кадров экрана.
     - *Main Thread FPS:* Частота отрисовки 3D-сцены в браузере.
     - *Scheduler Overruns / Dropped:* Что происходит, когда ОС задерживает таймер браузера (ограничение догоняющих шагов до 8 предотвращает зависание симуляции).
  5. **Источник ввода (`Demo input` против `USB / EdgeTX`):** Как управлять полётом с помощью экранного ползунка газа или подключить аппаратуру EdgeTX/OpenTX по USB в режиме джойстика.
  6. **Правило блокировки взведения (`Arm motors`):** Объясняет, почему настоящие дроны (и MirageSITL) требуют **0% газа** перед взведением моторов и почему сворачивание вкладки или потеря сигнала вызывают автоматическое аварийное отключение (Failsafe).
  7. **Калибровка USB-каналов и канала режимов:** Объясняет назначение осей Roll/Pitch/Yaw/Throttle, мёртвую зону (`3.5%`), инверсию и 6-позиционный канал переключения режимов полёта.
  8. **Статус системы (`Worker / SAB`, `Serial API`, `Input protection`):**
     - *Worker / SAB:* Что такое неблокирующая общая память `SharedArrayBuffer`.
     - *Serial API (HITL):* Как Web Serial считывает живые кадры MAVLink `HEARTBEAT` и `EKF_STATUS_REPORT` с полётного контроллера по USB.
     - *Input Protection:* Объясняет работу сторожевого таймера ввода пилота `250 ms` (`INPUT LIVE` против `DISARMED / STALE`).

### C. Консоль инструктора и регистратор полётов AAR ([`Console.tsx`](../../apps/web/src/instructor/Console.tsx), [`Export.tsx`](../../apps/web/src/aar/Export.tsx), [`Review.tsx`](../../apps/web/src/aar/Review.tsx))
- **Тактические иконки:**
  - `Radar`, `Zap`, `Wind`, `Box`, `Terminal` в [`Console.tsx`](../../apps/web/src/instructor/Console.tsx).
  - `CircleDot` (Запись), `Square` (Стоп), `Eye` (Разбор), `Download` (Экспорт), `Upload` (Импорт) в [`Export.tsx`](../../apps/web/src/aar/Export.tsx).
- **Подсказки для начинающих (`InfoTip`):**
  1. **Консоль инструктора и горячие клавиши (`P`, `R`, `F`):** Как работает ввод отказов инструктором после подтверждения (ACK) от физического потока.
  2. **Эффекты отказов (`gnss-jamming`, `position-step`, `velocity-drift`, `magnetic`, `motor-loss`):** Доступное описание каждого режима радиоэлектронной борьбы (РЭБ / EW) и аппаратных отказов (например, как подавление GNSS ухудшает спутниковую навигацию и как затухают обороты винта при отключении питания мотора).
  3. **Погода и загрузка модели:** Почему команды ветра и загрузки пользовательской модели требуют полного аэродинамического бэкенда и наглядно отклоняются в демо-режиме.
  4. **Запись сессии и разбор полёта AAR (`.aar`):** Как система послеполётного разбора (After-Action Review) записывает каждый шаг физики в кольцевой буфер объёмом до `32 MiB` и строит графики управляющего сигнала пилота, привода и угловой скорости крена.

### D. Вкладки `Project`, `Aircraft`, `Components` и `Sensors`
- **Тактические иконки:** Иконки заголовков разделов (`FolderPlus`, `Archive`, `HardDrive`, `Compass`, `Scale`, `Cpu`, `Wrench`, `Activity`).
- **Подсказки для начинающих (`InfoTip`):**
  - **Вкладка Aircraft ([`AircraftEditor.tsx`](../../apps/web/src/aircraft/AircraftEditor.tsx), [`ArmTable.tsx`](../../apps/web/src/aircraft/ArmTable.tsx), [`MassProperties.tsx`](../../apps/web/src/aircraft/MassProperties.tsx)):**
    - *Лучи и соосная схема:* Что означают азимутальный угол луча, длина луча, угол наклона (cant) и верхние/нижние моторы соосной пары.
    - *Масса и тензор инерции ($I_{xx}, I_{yy}, I_{zz}$):* Понятное объяснение центра масс и моментов инерции (сопротивления угловому ускорению по крену, тангажу и рысканью).
  - **Вкладка Components ([`ComponentsPanel.tsx`](../../apps/web/src/library/ComponentsPanel.tsx), [`CalculationPanel.tsx`](../../apps/web/src/library/CalculationPanel.tsx)):**
    - *Карточки компонентов:* Что означают постоянная оборотов $K_v$ (об/мин на вольт), внутреннее сопротивление обмотки $R_m$, ток холостого хода $I_0$, а также C-рейтинг и внутреннее сопротивление батареи.
    - *Режим расчёта (`Preliminary` против `From measurements`):* Разница между предварительным расчётом по паспортным данным и привязкой стендовых измерений тяги.
  - **Вкладка Sensors ([`SensorsTab.tsx`](../../apps/web/src/sensors/SensorsTab.tsx)):**
    - *Режимы ошибок датчиков (`Ideal` против `With specified errors`):* Как смещение нуля (bias), белый шум, случайное блуждание и ошибки масштабного коэффициента влияют на показания ИНС (IMU), GNSS, барометра и магнитометра, и что означает колонка владельца (`MirageSITL` против `ArduPilot SITL`).
