# AGENTS.md

English source. [Russian mirror](docs/ru/AGENTS.md).

This file is a pointer, not a policy. The authoritative agent workflow for
this repository is the root [CLAUDE.md](CLAUDE.md). Open and read it before
every iteration, then follow its rules for language, documentation
synchronization, task execution, verification, and evidence.

Do not copy rules from CLAUDE.md into this file or any other agent
configuration. When a rule changes, change CLAUDE.md and its Russian mirror
only. Whether a given client loads this file automatically depends on that
client; if unsure, open CLAUDE.md explicitly.

CLAUDE.md in turn directs agents to the approved
[PROJECT_SCOPE.md](PROJECT_SCOPE.md) and the [Phase 1 plan](docs/PHASE1_PLAN.md)
before they pick a task.
